# Antriana Sofroniou — Personal Website

A simple, responsive CV/portfolio website using plain HTML, CSS, and JavaScript. No build tools required.

## Preview locally

Double-click `index.html` to open in your browser. Internet access is helpful for the optional Google Fonts; fallback fonts work offline.

## Publish free using GitHub Pages

1. Sign in at https://github.com and click **+** → **New repository**.
2. Name the repository `antriana-cv` (or choose another name), set it to **Public**, and click **Create repository**.
3. In the repository, select **Add file** → **Upload files**.
4. Upload the **contents** of this folder: `index.html`, `style.css`, `script.js`, `cv.pdf` (and optionally this README). Do **not** upload only the ZIP archive.
5. Click **Commit changes**.
6. Go to **Settings** → **Pages**. Under **Build and deployment**, select **Deploy from a branch**; select branch **main** and folder **/(root)**, then **Save**.
7. Your website's address will be `https://YOUR-USERNAME.github.io/antriana-cv/` if you used that repository name. Wait for GitHub to show the successful Pages deployment.

For an address with no repository suffix, name the repository `YOUR-USERNAME.github.io` instead; then your site will be `https://YOUR-USERNAME.github.io/`.

## Edit your content

- `index.html`: name, sections, text, emails, and contact information.
- `style.css`: colors, spacing, fonts, and layout.
- `script.js`: mobile menu and footer year.
- `cv.pdf`: downloadable original CV. Replace this file with an updated PDF as needed.

**Privacy:** The site is public. It currently contains the email addresses and phone number from the original CV. Remove any contact details you don't want searchable online before publishing.

**CV fidelity:** Content is based on the supplied PDF and lightly edited for website readability. The supplied CV did not include your current master's program; consider adding it to the Education section before publishing.
